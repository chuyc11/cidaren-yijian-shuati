# 常见问题

[返回首页](../README.md) · [使用指南](QUICKSTART.md) · [反馈问题](https://github.com/chuyc11/Easy-Cidaren-Fixed/issues/new/choose)

## 下载与启动

### 普通使用者应该下载哪个文件？

选择 `Easy_Cidaren_Fixed-windows-x64.zip`。`Easy_Cidaren_Fixed-source.zip` 是对应发布标签的源码，GitHub 的「Code → Download ZIP」也只下载源码。

### 需要安装 Python 或 AI 软件吗？

Windows 运行包已经包含 Python 运行依赖与本地英语模型，不需要另行安装。AI 配置是可选项；处理词达人任务仍需要网络和自己的有效 Token。

### 为什么单独拿出 EXE 后打不开？

程序需要同目录里的配置、模型、Qt 插件和其他运行库。请完整解压，并保留文件结构。配置和日志也需要可写目录。

### 支持哪些系统？

当前提供 Windows x64 运行包。尚未发布或验证 macOS、Linux 和 Windows ARM 原生运行包。

## 登录与任务

### 下载包里有 Token 吗？怎么获取？

没有。需要自行准备自己账号的有效 Token。本发布包不附带第三方 Token 获取工具；界面里保留的上游获取入口不代表其外部依赖已随包分发。

### 提示 Token 过期怎么办？

更新为当前有效 Token 后重新登录，再刷新任务。重复输入服务器已判定失效的 Token 不会恢复登录。

### 登录后看不到目标任务怎么办？

先确认登录的是正确账号、已切换到对应的自学或测试列表，并点击「刷新任务」。任务是否可执行，以平台当前的发布状态、进度和截止状态为准。

## 运行与恢复

### 为什么遇到某道题会停下来？

班级测试遇到无法可靠作答的题目，会保留当前进度并提示处理。检查可选 AI 配置，或在词达人中自行完成该题后刷新并恢复。练习中部分歧义题可能被暂时跳过并记录原因；请根据右侧输出信息判断具体情况。

### 快速模式为什么仍有等待？

快速模式主要减少额外间隔。网络请求、服务器响应、首次模型加载和 AI 调用仍需要时间，部分请求也需要重试或顺序处理。

### 中断后会从头开始吗？

程序保存恢复信息，并在恢复前重新核对服务器当前状态。可恢复的记录会显示「恢复中断任务」入口。请使用原解压目录登录同一账号；更换目录不会自动带走旧目录中的记录。

### 可以保证所有题型都完成吗？

不能。平台题型、课程内容、任务规则或验证流程可能变化。当前发布版已有 166 项离线回归测试和 9 项成品自检，但这些检查不等于所有线上课程都能完成。

## 数据与反馈

### 配置、学习数据和日志放在哪里？

保存在当前解压目录中的 `config`、`cache`、`log` 等位置。恢复记录和任务报告按账号分别保存；词表池与自学习答案库属于这个程序目录的学习数据。

### 怎样提问更容易定位问题？

使用[问题反馈表](https://github.com/chuyc11/Easy-Cidaren-Fixed/issues/new?template=bug_report.yml)，填写版本、Windows 版本、任务类型、复现步骤和错误信息。截图与日志先去除姓名、账号、Token 和 API Key。无需提供真实班级题库或完整个人任务记录。
