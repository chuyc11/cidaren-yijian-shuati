# 使用指南

[返回项目首页](../README.md) · [常见问题](FAQ.md) · [下载最新版本](https://github.com/chuyc11/Easy-Cidaren-Fixed/releases/latest)

## 下载与打开

1. 下载 `Easy_Cidaren_Fixed-windows-x64.zip`，普通使用者选择运行包即可。
2. 将整个压缩包解压到可写目录，例如个人文档中的独立文件夹。
3. 双击 `Easy_Cidaren_Fixed.exe`。不需要安装 Python，也不需要另行下载词形模型。

请保留 EXE 旁的配置、资源、模型和依赖文件。不要在压缩软件的预览窗口中直接运行，也不要单独复制 EXE。

## 登录与任务选择

使用自己账号的有效 Token，在「用户 token」输入框中填写后点击「登录」。本项目不提供账号或 Token，当前运行包也不包含第三方获取工具。

登录成功后，选择「班级自学任务」或「班级测试任务」。如果刚刚在词达人中完成了部分内容，可先点击「刷新任务」，以当前服务器状态为准。

- **只执行一项**：选中对应任务，点击「开始任务」，核对弹窗中的任务名后确认。
- **依次执行多项**：点击「一键刷题」，核对任务数量后确认。程序会依次处理当前列表中可执行的未完成任务。
- **中止运行**：点击「中止任务」，等待后台处理结束后再切换任务。

不要把自己的 Token 填进公开 Issue 或分享文件。

## 速度与设置

通过「设置 → 首选项」调整快速模式和相关间隔。快速模式默认开启，用于减少额外等待；词形模型会在需要时加载并复用，词表数据也会缓存和预取。

实际速度还取决于网络、平台响应、题型和是否需要调用 AI。首次加载模型与后续复用的耗时可能不同。

## 中断后如何继续

1. 查看右侧输出信息，确认是网络问题、Token 失效，还是当前题无法可靠作答。
2. 按提示处理问题；需要时更新 Token 并重新登录。
3. 刷新任务。如果检测到可恢复的中断记录，点击「恢复中断任务」。

恢复前会重新核对服务器上的任务状态，继续使用当前题目与进度。如果班级测试停在无法可靠作答的题目，可检查 AI 配置，或在词达人中自行完成该题后再恢复。

## 查看测试报告

有对应记录时，可以点击「测试报告」查看题目记录、服务器判分及统计。报告和恢复信息按账号分别保存；它们在运行后生成，原始下载包不含其他人的账号记录。

## 可选AI配置

未配置 AI 时，程序仍会使用本地规则和英语词形模型。需要 AI 辅助时：

1. 在 `config` 目录，将 `ai_config.example.json` 复制为 `ai_config.json`。
2. 根据所选服务填写以下字段。
3. 保存后重启程序。

```json
{
  "base_url": "https://你的服务地址/v1",
  "api_key": "填写你自己的API Key",
  "model": "服务支持的模型名称",
  "timeout": 30
}
```

接口需兼容 OpenAI 格式的聊天补全请求；`base_url` 填写 API 基础地址，程序会追加 `/chat/completions`。费用与额度以所选服务为准。

配置可读并不等于接口一定可用。出现鉴权、网络或模型名称错误时，先核对服务提供的配置说明。不要分享已填写密钥的文件。
